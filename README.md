# SPRIX Physics

- `index.html`: login screen copied from SPRIX Chemistry, including the same SPRIX LEARNING logo and show-password control. Like the current Chemistry login implementation, this screen does not validate against a username/password database; it stores a local login flag and opens `platform.html`.
- `platform.html`: Physics platform shell and branding.
- `app.js`: Physics lessons and interactions. The supplied Photon robot and Nichu student images are embedded as Base64 data URLs, so the images do not depend on external hosting.
- `style.css`: original physics styles.

Character names: Photon (فوتون) and Nichu (نيتشو).
